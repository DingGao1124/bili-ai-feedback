# 开发记录

记录关键功能性变更。**后续智能体修改代码后，若涉及功能、接口、数据结构、环境变量等对外契约，必须在此追加一条**（日期 + 改动摘要 + 位置/影响）。按时间倒序排列。

## 记录

- 2026-08-20 **视频信息渐进式渲染** —— 新增 `meta_ready` 事件：后端 `setMeta` 在视频信息读取完成后即推送，前端 `use-analysis-stream.ts` 收到后刷新任务视图，使视频卡片在 `getVideoMeta` 结束后立即展示（弹幕/评论仍在抓取时其余区块保持加载态），不再等弹幕与评论全部抓完才一起出现。
- 2026-08-20 **模型配置环境变量化** —— `apps/server/src/services/feedback-agent.service.ts` 移除硬编码 `MODEL_NAME` 与推理强度，改为读取 `DEEPSEEK_MODEL` / `DEEPSEEK_REASONING_EFFORT`（默认 `deepseek-v4-flash` / `medium`）；`apps/server/.env.example`、README 环境变量表与 `docs/项目架构.md` 同步更新。
- 2026-08-20 **原始数据抓取完成即展示** —— 修复 `/workspace/:jobId` 任务视图仅在 AI 完成时才刷新的问题；`apps/web/src/hooks/use-analysis-stream.ts` 现于 `status` 阶段切换（fetching/preprocessing/semantic_mapping/agent_running/validating）时同步刷新任务视图，视频信息、弹幕密度、评论等级分布与原始弹幕/评论列表在数据抓取完成、AI 分析期间即可渲染，右侧 Agent 面板的阶段文案与进度条也随阶段实时更新，不再等到最终 `completed`。
- 2026-08-20 **收敛失效任务的重复请求** —— API 客户端合并并发重复 GET；报告页移除未使用的任务详情请求。后端重启导致内存任务失效时，旧报告链接只产生一次 404，并展示返回首页重新分析入口。
- 2026-08-20 **一键启动脚本** —— 新增 `scripts/dev.mjs`，root `dev` 改为先启动后端、轮询等待 3001 就绪后再启动前端，消除 Vite 抢跑产生的 ECONNREFUSED 启动日志；`dev:server` / `dev:web` 仍可单独启动。
- 2026-08-20 **重构为双页面异步 AI 分析平台** —— 新增 `/workspace/:jobId` 原始数据与 Agent 过程页、`/report/:jobId` 创作复盘页；前端引入 React Router、Zustand、Markdown，并严格沿用参考项目的 MessageScroller、消息气泡、折叠思考和工具调用卡交互。后端以任务队列、60 分钟内存 TTL、SSE + JSON 历史回放、热门 2000 + 最新 500 评论、当前弹幕池、分层样本和证据回查替代旧同步 `/api/analysis`。AI 改为 LangChain `createAgent` + `ChatDeepSeek(deepseek-v4-flash)`，使用三个报告写入工具，不再生成启发式伪报告；模型证据会按 ID 回填真实原文并过滤无效引用。新增 `docs/AI分析任务接口.md`，请求日志升级为脱敏 req/res 拦截器。
- 2026-08-18 **package.json 加 engines 约束** —— root `package.json` 增加 `engines.node: ">=22"`；README「环境要求」表 Node 版本同步改为 ≥ 22。
- 2026-08-18 **README 安装指引细化** —— 新增「安装与运行」分步说明：环境要求（bun ≥1.0 / Node ≥20）、bun 各平台安装方式（macOS 官方脚本/Homebrew、Linux/WSL、Windows/PowerShell）与验证命令、依赖安装、环境变量、启动步骤；面向未装 bun 的新用户。
- 2026-08-18 **弹幕/评论拉取去截断 + 摘要如实化** —— ①弹幕单窗口返回达 ~2000 条时服务端会截断（实测上限约 2474 条），`bilibili.service` 改为窗口内二分细分递归拉全（`collectDanmaku`），`getDanmaku`/`getDanmakuWindow` 均受益；②评论分析采样上限从 10 页提至 50 页（约 1000 条）；③`analysis.service` 摘要文案区分「当前弹幕池 vs 历史累计弹幕」「按热度采样评论」，不再把采样数冒充全量；④`heuristics.ts` 热词过滤纯数字与含数字/全同字符的 2-gram（如「20」「02」「啊啊」）。
- 2026-08-18 **新增基础请求日志** —— `common/request-logger.middleware.ts`（方法 + 路径 + 状态码 + 耗时，>=500 error / >=400 warn / 其余 log），`main.ts` 全局注册 `app.use(requestLogger)`；日志前缀 `HTTP`。
- 2026-08-18 **收紧钩子凭据规则** —— `.githooks/secret-patterns` 各 B 站 cookie 字段（SESSDATA/bili_jct/buvid3/DedeUserID/bili_ticket）增加可选空格+引号容忍，`SESSDATA="..."` 带引号写法也能拦截；空赋值（`SESSDATA=`）不误报。
- 2026-08-18 **钩子改为 install 自动安装** —— 根 `package.json` 增加 `postinstall` 设置 `core.hooksPath=.githooks`（非 git 仓库时静默跳过）；克隆后 `bun install` 即自动带钩子，无需任何手动操作。
- 2026-08-18 **新增 pre-commit 钩子** —— `.githooks/pre-commit`（拦截 `.env`/凭据/冲突标记 + 跑 typecheck），`core.hooksPath` 指向 `.githooks`；凭据规则在 `.githooks/secret-patterns`；由 `postinstall` 自动安装。
- 2026-08-18 **Cookie 有效期分析** —— 见 `docs/Cookie_说明.md`。实测 SESSDATA 2027-02-14 过期、bili_ticket 2026-08-21 过期（约 3 天，需定期刷新，否则部分接口风控）。
- 2026-08-18 **评论/弹幕分页拉取接口** —— 新增 `BilibiliController`：`GET /api/bilibili/:bvid/{meta,danmaku,comments}`；`bilibili.service` 增加 `getDanmakuWindow` / `getCommentPage`；`types.ts` 增加 `DanmakuPage` / `CommentPage`（`Comment` 增 `avatar`）。前端 `lib/api.ts` 增 `fetchDanmaku` / `fetchComments`，`components/result/` 增 `DanmakuList` / `CommentList`。
