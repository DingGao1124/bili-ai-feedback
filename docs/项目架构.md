# 项目架构

B站评论弹幕 AI 分析工具 —— 面向 UP 主的观众反馈分析平台。输入视频链接或 BV 号，自动抓取评论与弹幕，生成话题摘要、情感分布、弹幕时间轴情绪曲线、Top5 高价值反馈。

## 技术栈

- 包管理 / 运行时：**bun**（workspaces monorepo）
- 后端 `apps/server`：NestJS 11 + TypeScript
  - WBI 签名 + protobuf 弹幕解码 + 评论抓取（`BilibiliService`）
  - LLM 摘要（OpenAI 兼容网关，未配置时回退本地启发式）
- 前端 `apps/web`：Vite + React 19（React Compiler）+ TypeScript + Tailwind CSS v4 + shadcn/ui + Recharts

## 关键设计决策

| 决策 | 理由 |
|---|---|
| bun monorepo（`workspaces: ["apps/*"]`） | 根脚本用 `bun run --filter '*'` 并行起前后端，去掉 concurrently |
| 后端按类型分目录（controllers/services/modules/utils） | 按用户要求，参考既有项目结构；不按 feature 分 |
| 不用 `packages/shared`，types 在 server/web 各存一份 | shared 源码被拉进编译会让 dist 嵌套到 `dist/apps/server/src/`；删除后加 `rootDir=./src`，产物扁平为 `dist/main.js`，`start:prod` 用 `node dist/main.js` |
| `POST /api/analysis` 一次性完整分析 + `GET /api/bilibili/:bvid/{meta,danmaku,comments}` 分页拉取 | 完整分析 与 原始数据浏览互补；分页语义见 `docs/弹幕评论拉取接口.md` |
| 摘要/Top5 优先 LLM，未配置回退本地启发式 | 无 LLM 也能端到端跑通 demo；返回 `aiGenerated` 字段标识来源 |

## 运行

```bash
bun install
cp apps/server/.env.example apps/server/.env

bun run dev            # web :5173 + server :3001（/api 已配 vite 代理）
bun run dev:server     # 只起后端
bun run dev:web        # 只起前端
```

校验：`bun run typecheck` / `bun run build`（用 `bun run --filter '*'` 跑全部 workspace）。

## 环境变量（apps/server/.env）

| 变量 | 说明 |
|---|---|
| `PORT` | 后端端口，默认 3001 |
| `BILI_COOKIE` | B 站登录态 cookie（字段与有效期见 `docs/Cookie_说明.md`） |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | OpenAI 兼容网关；留空则分析回退本地启发式摘要 |

## 数据流

1. 前端输入 BV 号 → `POST /api/analysis {input}`
2. 后端 `parseBvid` → `getVideoMeta`（`x/web-interface/view` 拿 aid/cid/标题/封面/统计）
3. 并行拉取：`getDanmaku`（按 2 分钟时间窗 + WBI 签名拉 `seg.so` protobuf）、`getComments`（游标翻页热度评论）
4. 本地确定性算法算热词、情感分布、时间轴曲线
5. LLM 生成摘要 + Top5 高价值反馈；失败回退启发式（`heuristics.ts`）
