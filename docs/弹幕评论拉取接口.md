# 弹幕 / 评论拉取接口（REST）

本文档描述 `apps/server` 暴露的原始数据拉取接口，供前端「弹幕」「评论」两个 Tab 分页渲染使用。
与 `/api/analysis`（一次性完整分析）互补。

## 接口总览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bilibili/:bvid/meta` | 视频基础信息（aid/cid/标题/时长等） |
| GET | `/api/bilibili/:bvid/danmaku?start=<ms>` | 一个时间窗（2 分钟）的弹幕 |
| GET | `/api/bilibili/:bvid/comments?mode=<2\|3>&offset=<游标>` | 一页评论（游标翻页） |
| POST | `/api/analysis` | 完整分析（热词/情感/时间轴/摘要） |

所有接口的 `:bvid` 参数为视频 BV 号（如 `BV1j4411W7F7`），后端内部统一转成 aid/cid。

## 弹幕分页（`danmaku`）

### 关键语义（实测）

- B 站弹幕按**时间窗**拉取，`ps`/`pe` 是**绝对毫秒**（相对视频起点），不是相对分片。
- `segment_index = floor(start / 360000) + 1`（每个 segment 覆盖 6 分钟）。
- **不带 `ps`/`pe` 时，服务端会把返回截断到约前 60 秒 / 3000 条**，热门视频会严重漏拉。
  因此必须始终携带 `ps`/`pe`。
- 本服务采用 **2 分钟（120000ms）一个窗口**作为分页单位，与 B 站 web 播放器一致；
  窗口大小与 6 分钟 segment 边界天然对齐（`360000 % 120000 === 0`），不会跨 segment。
- **单窗口请求返回条数达到约 2000 条时服务端可能截断**（实测上限约 2474 条），
  因此后端会对该窗口**二分细分递归拉取**，直到每个子窗口都取全，再合并返回。
  所以单页返回的弹幕是「窗口内全量」，不会因热门视频弹幕过密而漏拉。

### 请求

```
GET /api/bilibili/:bvid/danmaku?start=0
```

`start` 为窗口起点毫秒，后端会向下取整到 120000 的整数倍。

### 响应（`DanmakuPage`）

```json
{
  "items": [ /* Danmaku[] */ ],
  "start": 0,
  "end": 120000,
  "hasMore": true
}
```

- `end` 为窗口终点（不含），`hasMore = end < 视频时长毫秒`。
- 前端「加载更多」用上一次响应的 `end` 作为下一次的 `start`。

## 评论分页（`comments`）

### 关键语义（实测）

- 用 `reply/wbi/main` 的**游标**翻页，而不是老的 `pn/ps`。
- 第一页 `pagination_str = {"offset": ""}`；后续页用上一页响应里的
  `cursor.pagination_reply.next_offset` 作为 `offset`。
- `mode=3` 热门（默认），`mode=2` 按时间。
- 每页约 20 条，响应里 `cursor.all_count` 是评论总数，`cursor.is_end` 标记末页。

### 请求

```
GET /api/bilibili/:bvid/comments?mode=3&offset=CAEiAggC
```

`offset` 省略或为空表示第一页。

### 响应（`CommentPage`）

```json
{
  "items": [ /* Comment[]，含 avatar */ ],
  "nextOffset": "CAEiAggD",
  "isEnd": false,
  "allCount": 218951
}
```

- `isEnd` 为 true 时 `nextOffset` 返回空串。
- 前端「加载更多」用 `nextOffset` 作为下一次的 `offset`。

## 数据契约

分页类型定义在 `apps/server/src/types.ts` 与 `apps/web/src/types.ts`（两份保持一致）：

- `DanmakuPage { items, start, end, hasMore }`
- `CommentPage { items, nextOffset, isEnd, allCount }`
- `Comment` 新增 `avatar` 字段（发布者头像 URL）。

## 实现位置

- `apps/server/src/services/bilibili.service.ts`：`getDanmakuWindow` / `getCommentPage`（分页），
  `getDanmaku` / `getComments`（分析用全量/上限拉取，复用分页原语）。
- `apps/server/src/controllers/bilibili.controller.ts`：路由定义。
- `apps/web/src/lib/api.ts`：`fetchDanmaku` / `fetchComments`。
- `apps/web/src/components/result/DanmakuList.tsx` / `CommentList.tsx`：分页渲染 + 「加载更多」。
